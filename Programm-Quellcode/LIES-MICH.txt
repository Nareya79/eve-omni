EVE Omni - Programm mit Overlay
==============================

Früher hieß das Programm EVECore. Beim ersten Start übernimmt EVE Omni alle Daten
(Einstellungen, Trades, Logins, Sicherungen) aus EVECore. Der alte Ordner EVECore
kann danach weg.

1. Einrichten (einmalig)
------------------------
- Diesen Ordner an einen festen Platz legen, z. B. Dokumente\EVE-Omni-Programm.
- EVE-Omni.exe doppelklicken.
- Windows warnt beim ersten Start ("Der Computer wurde durch Windows geschützt"),
  weil das Programm nicht signiert ist: "Weitere Informationen" -> "Trotzdem ausführen".
- Das Programm legt beim ersten Start eine Verknüpfung im Startmenü an (nötig für
  Windows-Meldungen bei überbotenen Orders).

2. Deine Daten aus Chrome übernehmen
------------------------------------
- In Chrome wie gewohnt EVE-Omni.html öffnen -> Einstellungen -> "Daten sichern & übertragen"
  -> "Daten exportieren". Mit Häkchen "Logins mit exportieren" musst du dich im Programm
  nicht neu einloggen (die Datei dann wie ein Passwort behandeln und danach löschen).
- Im Programm: Einstellungen -> "Importieren" -> Datei wählen -> "Jetzt übernehmen".
- Ohne Logins: im Programm unter Konto neu einloggen. Das Login-Fenster erledigt den
  Rest automatisch, du musst keine Adresse mehr kopieren.
- In deiner EVE-Developer-App musst du nichts ändern.

3. Overlay über EVE
-------------------
- EVE muss im Fenster- oder randlosen Modus laufen (nicht echtes Vollbild).
- Knopf "Kompakt" oben rechts -> kleines Overlay mit Trades, Route, Skills, Wallet.
- Verschieben: an der oberen Leiste ziehen. Größe: Ecke unten rechts ziehen.
- Einzelfenster: Jede Ansicht (Trades, Route, Skills, Wallet, Scanner-Plan, Hauling,
  Hub-Handel, Local, Charaktere, Planeten, Jukebox) kann ein eigenes kleines Fenster bekommen - Knopf mit den zwei Rechtecken
  in der Kompaktansicht oder Einstellungen -> Ansichten -> "eigenes Fenster".
  Frei platzieren, die Position wird gemerkt.
- Transparenter Hintergrund gilt für Kompaktansicht, Hauptansicht und Einzelfenster.
- Einrasten: Schiebst du ein Overlay-Fenster nah an ein anderes oder an den
  Bildschirmrand, rastet es bündig ein (wie in EVE). Zum Lösen einfach ein Stück
  weiterziehen (etwa 45 Pixel). Abschaltbar unter Einstellungen -> Programm.
- Größe aller Overlays: Einstellungen -> Kompaktansicht -> "Overlay-Skalierung" (60-200 %).
- Neocom-Reihenfolge: Symbole links einfach mit der Maus an eine andere Stelle ziehen
  oder Einstellungen -> Darstellung -> Neocom-Reihenfolge.
- Tastenkürzel (änderbar unter Einstellungen -> Programm):
    Strg+Umschalt+E   Durchklicken ein/aus (Mausklicks gehen auf EVE)
    Strg+Umschalt+O   Ein-/Ausblenden
    Strg+Umschalt+K   Kompakt <-> Groß
    Strg+Umschalt+N   Nächste Kompaktansicht
    Strg+Umschalt+L   Local prüfen (nur nötig, wenn die automatische Erkennung aus ist)
    (Jukebox: Abspielen/Weiter/Zurück - ohne Vorgabe, z. B. die Medientasten eintragen)
- Symbol unten rechts in der Taskleiste: Rechtsklick für alle Schalter und "Beenden".
- Alle Schalter (Vordergrund, Transparenz, Deckkraft, Autostart, Sicherung) findest du
  unter Einstellungen -> Programm.

3a. Neu in 1.3 (Ideen aus RIFT)
-------------------------------
- Intel / Local (seit 1.3.1 wie bei RIFT): Im EVE-Local in die Mitgliederliste klicken, Strg+A, Strg+C
  -> das Overlay-Fenster "Local" geht von selbst auf: jeder Pilot mit Allianz-Kürzel, Balken für
  Gefahr und Gang, Kills/Verluste (zKillboard). Abschaltbar: Einstellungen -> Programm.
- Jukebox: offizielle EVE-Musik über Spotify direkt im Programm (für ganze Titel im Player anmelden).
- Neocom als Overlay (1.3.2): Einstellungen -> Programm -> "Neocom als eigenes Overlay-Fenster".
  Symbolleiste frei platzieren, an der Ecke unten rechts größer/kleiner ziehen (Symbole wachsen mit,
  breit gezogen = waagerecht). Klick = Overlay-Fenster der Ansicht an/aus, Rechtsklick = große Ansicht.
  Einstellungen/Assets/usw.: Klick öffnet das Hauptfenster dort, nochmal klicken schließt es wieder.
  Ganz unten "Beenden": zweimal klicken beendet EVE Omni (erster Klick färbt den Knopf rot).
  Seit 1.3.4: Die Symbole ordnen sich beim Größe-Ändern als Raster an (schmal = Spalte, breit = Reihe,
  quadratisch = Raster). Maus drüber zeigt den Namen. Welche Symbole erscheinen: Einstellungen ->
  Programm -> "Symbole im Neocom-Overlay auswählen".
- Aussehen wie in EVE (1.3.4, Standard): Einstellungen -> Kompaktansicht -> "Overlay-Stil".

4. Neue EVE-Omni-Versionen
-------------------------
Unter Einstellungen -> Programm -> "Andere Datei wählen" deine EVE-Omni.html aus dem
Projektordner wählen (Dokumente\CLAUDE\EVE Omni\EVE-Omni.html). Dann wirkt jede neue
Version sofort im Programm.

4b. EVE-Clients mit Tab durchschalten (neu in 1.5.1)
---------------------------------------------------
Ersetzt das Umschalten von EVE-X-Preview. Einschalten unter Einstellungen -> Programm ->
"EVE-Clients umschalten":
  1. In EVE-X-Preview das Umschalten mit Tab ausschalten (sonst schalten beide gleichzeitig).
  2. In EVE Omni den Haken "Mit einer Taste durch die EVE-Clients schalten" setzen.
  3. Reihenfolge mit den Pfeilen festlegen ("nach vorne" holt einen Client testweise nach vorne).
Tab = nächster Client, Umschalt+Tab = vorheriger (beides änderbar). Wirkt nur, wenn ein
EVE-Client vorne ist und mindestens zwei laufen. EVE bekommt diesen Tastendruck dann nicht
(auch nicht im Chat). Alt+Tab bleibt normal.

5. Sicherungen
--------------
Täglich automatisch nach Dokumente\EVE-Omni-Sicherungen (die letzten 14). Zurückholen:
Einstellungen -> Importieren -> Sicherungsdatei wählen.

6. Entfernen
------------
Ordner löschen. Einstellungen und Daten liegen in %APPDATA%\EVE Omni,
die Verknüpfung im Startmenü unter "EVE Omni".

Das Programm liest die EVE-Schnittstelle (ESI) mit deinem Login und zeigt an. Einzige
Ausnahme: "Ziel im Spiel setzen" trägt auf deinen Klick ein Autopilot-Ziel über die
offizielle Schnittstelle ein. Es drückt keine Tasten im Spiel und fliegt nicht selbst. Beim Umschalten holt es nur
ein EVE-Fenster nach vorne (wie EVE-X-Preview).
Für die Local-Liste fragt es zKillboard (öffentliche Kill-Statistiken).
