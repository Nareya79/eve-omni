## Highlights

### 🖥️ Multi-Client-Vorschau – alle Clients, eine Taste
- **Live-Vorschau** aller EVE-Fenster in kleinen Kacheln immer im Vordergrund – Größe, Bildrate und Position bestimmst du.
- **Mit Tab durchschalten** (oder einer Taste deiner Wahl), Umschalt+Tab zurück – in deiner Reihenfolge, Charakterauswahl wird übersprungen.
- **Klick auf eine Vorschau** holt den Client nach vorne; ein goldener Rahmen zeigt den aktiven.
- **Fair Play:** ein Tastendruck wechselt ein Fenster. EVE Omni sendet nie Tasten oder Klicks ans Spiel und verteilt nie Eingaben auf mehrere Clients.

### 🪟 Overlay im Spiel – deine Werkzeuge direkt über EVE
- Kleine, durchsichtige Fenster, die über dem Spiel schweben – nur solange EVE vorne ist.
- Ansichten: Trades · Watchlist · Handel · Wallet · Assets · Charaktere · Skills · Mining · Industrie · Wurmlöcher · Route · Karte · Local · Gang-Alarm · Jukebox
- Ein kompaktes Fenster oder jede Ansicht als eigenes Fenster, rastet am Bildschirmrand ein; Deckkraft je Fenster, Position sperren, automatisch ausblenden.
- Mit einem Klick exakte Preise kopieren, das Marktfenster eines Items in EVE öffnen oder das Autopilot-Ziel setzen.
- Local mit Strg+C kopieren und das Overlay zeigt, wer da ist; bei gemeldeten Feinden springt ein Live-Alarm auf.

## Download

Die erste öffentliche Beta kommt bald auf die [Releases-Seite](../../releases):

| Datei | |
|---|---|
| `EVE-Omni-Setup-<version>.exe` | Installer (keine Admin-Rechte nötig) |
| `EVE-Omni-<version>-portable.zip` | Ohne Installation |
| `EVE-Omni-Soundtrack.zip` | Musik |
| `SHA256SUMS.txt` | Prüfsummen zum Kontrollieren |

Voraussetzung: Windows 10/11, 64 Bit. Eine Browser-Version (eine HTML-Datei) liegt bei und läuft mit Einschränkungen auch auf anderen Systemen.

## Installation

1. **Herunterladen:** `EVE-Omni-Setup-<version>.exe` von der Releases-Seite.
2. **Installer starten.** Wenn Windows *„Der Computer wurde durch Windows geschützt“* zeigt: **Weitere Informationen → Trotzdem ausführen**.
   > Warum? EVE Omni ist ein kostenloses Hobby-Projekt ohne Code-Signatur (ein Zertifikat kostet jedes Jahr Geld). Zu jeder Version gibt es SHA256-Prüfsummen und einen VirusTotal-Scan.
3. **Mit EVE einloggen:** „Mit EVE einloggen“ klicken, auf der Login-Seite von CCP den Charakter wählen und bestätigen. Weitere Charaktere jederzeit.
4. **Losfliegen.** Handelsplatz wählen, Markt-Scanner öffnen, los geht's. o7

Kein Entwicklerkonto und keine API-Schlüssel nötig.

## Sicherheit & Datenschutz

- **Nur offizieller EVE-Login.** Du loggst dich auf der Seite von CCP ein (EVE SSO mit PKCE). EVE Omni sieht dein Passwort nie.
- **Deine Daten bleiben auf deinem PC.** Logins, Trades und Einstellungen liegen nur lokal – kein Konto, keine Cloud, kein Tracking.
- **Keine Automatisierung.** EVE Omni liest oder verändert nichts im Spiel-Speicher und sendet nie Eingaben ans Spiel.
- **Netzwerk:** CCPs ESI und Bild-Server (deine Daten und öffentliche Marktdaten), zKillboard, DOTLAN (eingebetteter Routen-/Sprungplaner) und EVE-Scout (`api.eve-scout.com`, öffentliche Thera/Turnur-Signaturen) – alles öffentliche Daten –, Google Fonts (Schriften) und einmal am Tag eine Update-Prüfung bei GitHub (abschaltbar). An den Entwickler wird nichts gesendet.

### Warum fragt der Login nach diesen Berechtigungen?
Jeder Bereich braucht Lesezugriff auf seine Daten. Nur zwei Berechtigungen *bewirken* etwas im Spiel – und nur, wenn du auf den Knopf klickst: Autopilot-Ziel setzen und ein Info-/Marktfenster öffnen.

| Wallet & Gewinne | `esi-wallet.read_character_wallet.v1`, `esi-wallet.read_corporation_wallets.v1`, `esi-corporations.read_divisions.v1` |
| Assets & Strukturen | `esi-assets.read_assets.v1`, `esi-universe.read_structures.v1` |
| Orders & Verträge | `esi-markets.read_character_orders.v1`, `esi-contracts.read_character_contracts.v1`, `esi-contracts.read_corporation_contracts.v1` |
| Industrie, Blueprints, Mining, PI | `esi-industry.read_character_jobs.v1`, `esi-characters.read_blueprints.v1`, `esi-industry.read_character_mining.v1`, `esi-industry.read_corporation_mining.v1`, `esi-planets.manage_planets.v1` (nur lesen) |

## FAQ

**Ist EVE Omni von CCP erlaubt?**
Es nutzt wie andere Drittanbieter-Tools nur die offiziellen, öffentlichen Schnittstellen von CCP (ESI und EVE SSO). Es liest oder verändert nichts im Spiel-Speicher und sendet keine Tastatur- oder Mauseingaben ans Spiel. Der Client-Umschalter holt nur ein EVE-Fenster nach vorne – eine Taste, ein Fenster.

**Kostet es etwas?**
Nein. Kostenlos, mit allen Funktionen, für immer – keine Premium-Version.

**Ich habe einen Fehler gefunden / eine Idee.**
Öffne ein [Issue](../../issues) (bitte mit EVE-Omni-Version und Windows-Version). **Poste nie Login-Tokens oder Codes.**

## Selbst bauen

Das Programm ist `EVE-Omni.html` plus die Electron-Hülle in `Programm-Quellcode/src/`. `build.js` baut den Windows-Ordner aus der offiziellen Electron-64-Bit-ZIP (Prüfsumme geprüft); `tools/installer.iss` ist das Inno-Setup-Skript für den Installer.

```
cd Programm-Quellcode/src && npm install          # koffi
cd .. && npm install resedit@3.1.0
node build.js <electron-win32-x64> <Zielordner>
```
